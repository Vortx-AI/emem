Examples · Beside web search

Ask the web for context. Ask emem for the measurement.

A web search returns pages about a place: articles, encyclopedia entries and forecasts, often undated and unsigned. emem returns a measurement of the place itself, read from orbit or an open sensor, with its date, its source and a signature any AI can check.

See three questions Connect your assistant

Get two kinds of answer for one place.

Use both. The web tells an agent what people have written. emem tells it what the place measured, on a date it can name and cite.

A web search returns

Find pages about the place

What
Articles, encyclopedia entries, travel pages, forecasts
When
The date the page was written, when it says one
Who measured
Often nobody named on the page
Checkable
By reading other pages

emem returns

Get a measurement of the place

What
One value at one address, with its unit and its method
When
The capture date of the scene or the sensor reading
Who measured
The named source: Sentinel-2, ERA5, JRC and more
Checkable
By any AI, with an emem:fact token and an Ed25519 signature

Use both in one answer.

An agent searches for the story, asks emem for the number, and checks its draft before anyone reads it. The two verdicts below came back from emem.dev on 25 November 2026.

  1. Search the web for context.

    History, names, plans and news: what people have written about the place.

    web search

  2. Ask emem for the measurement.

    The value at the place, its date, its source and an emem:fact token to cite beside it.

    emem_askemem_recall/v1/rain_series

  3. Check the draft before it is sent.

    Every token in the draft must resolve, and every number beside a token must match the signed value.

    emem_guard_verdict
