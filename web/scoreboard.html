the memory race

connecting turn —/— steps — worlds — models —
Two heats, deliberately. Some arms are handed the value and only have to reproduce it; the others must locate it first. On one track the first group sits near 100% and the second near zero, and you would conclude one architecture is several times better when they are doing different jobs.

check it yourself click an arm above

reading it

Byte-exact is whether the answer equals the signed value character for character, which is what a citation needs. Material is whether the error is big enough to change a decision. An arm can be materially perfect and never byte-exact, which is a rounded display, and that is why both are drawn. A retrieved chunk can be correct and still score 0% citable, because it is not a signed reference.
