Report text to signed fields

Paste the text of a residue report or a land record. emem parses it into fields, each tied to its line and byte offset, and signs the text hash and the result hash. This page checks both hashes and the signature itself.

writes
none; the parse and the OCR are not stored
checked
in this tab, with emem-verify-core.js
key
/.well-known/emem.json

What you will see

  • A report read row by row: analyte, result in mg/kg, the MRL the report prints, and whether it exceeds it.
  • The text hash, the result hash and the Ed25519 signature recomputed here, then broken on purpose.
  • The same report read from a picture by OCR, chained to the parse by the text hash.
1parse

The text becomes fields

The parser is deterministic. It reads what the document prints and quotes the line each value came from. It fills nothing in: a field it did not find is listed as missing.


      

    

  


  

    
2hashes

    

      
Check the text and the result

      
The receipt names the BLAKE3 of the text you sent and of the serialised result. This page hashes both here, then changes one digit in each and hashes again.

      

    

  


  

    
3signature

    

      
Check the signature here

      
The signature covers the parser kind, both hashes, the parser version, the time and the responder key. Nothing else. It says this text produced this result; it does not say the document is genuine.

      
digest = PreimageV1("emem.doc_parse.v1") {
  1: kind, 2: text_blake3, 3: result_blake3,
  4: parser, 5: parsed_at, 6: responder_pubkey }
valid = ed25519_verify(responder_pubkey, signature, digest)

      

    

  


  

    
4picture

    

      
The same report, read from a picture

      
This page draws the text onto a canvas, sends the PNG to /v1/ocr and checks the receipt against the bytes it sent. Then it parses the OCR response, which is refused if its text does not hash to what the OCR receipt signs.

      

      
      

    

  


  

    
What this does not show

    
    
      
  • That a reading is right. The OCR receipt is model_output: it signs which image, engine and language produced the text, not that the text is correct. Read the text before you trust a field parsed from it.
    • 
      
  • That a residue breaks the law. The parser compares each result with the MRL the report prints. It looks up the EU database only when you name the product in product, which this page does not do.
    • 
      
  • That the document is genuine. The parser is not a registry: it does not check a land record against the land registry, or a signature on the document.
    • 
      
  • That the fields are the ones a person would pick. Check each against the line it quotes; correct by hand when the document says otherwise.
