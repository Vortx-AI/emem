A verifiable memory of Earth that AI agents can read, write, and cite.

Ask an agent what is on the ground at a place it has never measured and it guesses, with no way to prove the answer. emem is the missing handle. Every patch of Earth gets a stable address, every measurement is one signed fact, and any agent or person can verify it offline without trusting the server that produced it.

02the gap

Ask an agent about a place, and it guesses.

A forest in Borneo, a floodplain outside Chennai, a field in Iowa. Ask an AI agent what is true on the ground there, and it improvises.

It has no shared handle for the patch of land you mean, and no way to prove the number it hands back. That was harmless when agents only answered questions. It stops being harmless once they act: filing compliance, pricing risk, triaging a disaster, releasing a payment. Roughly a quarter of organizations are already scaling agents that take real-world actions (McKinsey, 2025). Acting on an unverifiable guess has become a liability.

Every place on Earth becomes an address with a memory.

A cell64 addresses ground the way a token addresses text in an LLM. The planet is cut into fixed cells about 9.55 m across, and each one carries facts you can recall, verify, and cite.

A fact is one measurement at one cell, keyed by (cell, band, time) and packed in a fixed byte order so the same reading hashes the same way on every machine. That hash is the fact’s content id. Change one byte and the id changes, so the id proves the bytes. Ids that look alike sit physically near each other, so an agent that emits defi.zb493… already lands in roughly the right place.

the address algebrareadable, reproducible, content-addressedspec →
cell64 × band × tslot → fact, named by its own blake3 hash
defi.zb493.xuqA.zcb5f × copdem30m.elevation_mean × t.aaaaagy
cell64four base-1024 bigrams, dot-separated; Hilbert-ordered so neighbours share a prefix banda measurement type (elevation, rainfall, this year’s forest loss, a satellite embedding), auto-fetched and signed on first read tslota moment in time, base32 leb128 fact_cid32-byte blake3, base32, 26 chars; the durable handle you cite

The address is identical on every node, so two agents asking about the same ground reach the same memory. Nothing is pre-seeded. Ask about a place nobody has measured and the responder fetches the value from one of 46 real satellite sources, signs it, and returns it in the same response, then keeps it.

Don’t take our word. Take the receipt.

Every read returns a receipt: the responder’s public key, the signed payload, and the content id for each fact. Recompute the blake3 hash, check the ed25519 signature, and the answer reproduces in your own browser with no callback to us.

Ask emem.dev for the elevation under Denver and it returns the city’s nickname as a signed number, mile-high at 1609 m. Here is a real fact, exactly as the responder returned it:

The fact_cid is a durable handle. Paste it into a chat and a colleague pulls the same bytes from any node and checks the signature, on any day, in any year. Run enough nodes and you get a federation: independent responders that resolve the same ids byte for byte and write down where they disagree.

Four models read the same ground, and their disagreement is recorded.

Four independent foundation encoders, Clay, Prithvi, Tessera, Galileo, read the same cell. Where they agree, that agreement is a signal an agent can act on. Where two attesters sign different values at the same (cell, band, time), memory_contradictions scores the gap by band kind and records it, rather than averaging it away. A poisoned note can’t be slipped into a private agent memory the way MINJA (NeurIPS 2025) shows, because every fact here is signed and content-addressed.

05the memory layer
writes
signed, content-addressed files
kinds
episodic / semantic / procedural / resource
search
BGE-768 over LanceDB IVF_PQ
time
bi-temporal: valid-time + knowledge-time

A cache hands back a tile. A memory remembers.

On top of the fact store, an agent gets a memory it owns: it remembers what it saw, links it to what it saw before, and says so when two sources disagree.

Writes land as content-addressed, signed files. An agent makes a note, edits it, and finds it again next week by meaning rather than by filename, through a BGE-768 embedding search over a LanceDB index. The signature that proves a Sentinel-2 reading is the same one that proves the agent’s own notes are untouched. A path owned by one key turns away every other signer.

connect Typed temporal edges emem_edges_recall A fact carries signed connections, supersedes, relates_to, disagrees_with, bounded by valid-time. The graph is part of the record, not a side index.
reconcile Multi-attester contradictions memory_contradictions Where two signers disagree at the same cell, band, and time, the gap is scored per band kind, normalised spread for scalars, cosine for vectors, mode-share for categories.
cite Bundled citations memory_bundle Fold N facts into one signed envelope, memb:<bundle_cid>, that resolves to identical bytes on any peer. Hand over one handle for a whole finding.

Every read takes a bi-temporal bound. as_of_tslot asks what the world looked like at a past moment; as_of_signed_at asks what the system knew at one. The receipt records the bound, so an auditor in 2027 takes a 2026 receipt to any peer and replays the exact same query. A deterministic refinement loop re-derives a fact when a newer attestation or a disagrees_with edge lands, so the memory self-corrects instead of silently overwriting.

06who it’s for

What an agent can finally do, with the receipt attached.

Give an agent a memory of Earth it can cite, and the actions it can stand behind change. The same handlers answer agents over MCP and developers over plain REST.

  • Prove a shipment’s land was never cleared. The audit the EU requires under its Deforestation Regulation, in a year the tropics lost a record 6.7 million hectares of primary rainforest (WRI / Global Forest Watch). The endpoint signs an Annex II Due Diligence Statement against the Article 2(4) test.
  • Raise a flood or wildfire flag a day sooner. A single day of warning can cut disaster damage by up to a third (UN Early Warnings for All). Hunter mode sweeps a named region for twelve event types and returns signed hotspots.
  • Keep a carbon credit honest with continuous, signed evidence instead of a once-a-year spot check, every figure traceable to its source fact.
  • Defend a decision, a price, a claim, a route, with the place, the time, and the signature on record.

Or call it from a shell. Resolve a place to a cell, recall a band, and the answer comes back signed, auto-fetched if the cell is cold:

bashrest, no key
curl -s -X POST https://emem.dev/v1/recall \
  -H 'content-type: application/json' \
  -d '{"cell":"defi.zb493.xuqA.zcb5f","bands":["weather.temperature_2m"]}' \
  | jq '.facts[0]'

08where this goes

Where this is going.

emem is built to be a protocol, not a single service. Because every fact is content-addressed and signed, any responder can serve it and any client can verify it offline. Today that is one hosted responder and self-hosted nodes, and the hard part already ships beneath them: content addressing, signed receipts, typed temporal edges, multi-attester contradiction scoring, and a self-correcting refinement loop.

The design target is a federation of those responders, resolving the same facts byte-for-byte and cross-citing each other’s attestations, so the more of the world that is observed, the more trustworthy the shared memory becomes. Give it time, and Earth’s memory stops being something you query. It becomes a common record of the planet that any person, any company, and any agent can build on, and that no one has to take on faith.

Earth now has a memory. Help it remember.
