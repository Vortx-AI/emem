How it works

  1. Name it

    Hash the bytes. A file, a place, a reading or a model gets one short token.

    Bengaluru → defi.zb493.wIxI.zcb34

  2. Sign it

    Every fact is signed and appended to a public log that only grows.

    reading the log head…

  3. Check it

    Any agent re-hashes and verifies offline. No key, no account.
