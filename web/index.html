the problem

Ask an agent about a place, and it guesses.

A forest in Borneo, a floodplain outside Chennai, a field in Iowa. Ask an AI agent what is true on the ground there, and it will usually improvise.

It has no shared handle for the patch of land you mean, and no way to prove the number it hands back. That was harmless when agents only answered questions. It is not harmless now that they act: filing compliance, pricing risk, triaging a disaster, releasing a payment. Roughly a quarter of organizations are already scaling agents that take real-world actions (McKinsey, 2025). Acting on a guess has quietly become a liability.

the idea

So we gave the Earth a memory they can trust.

emem turns every place on Earth into an address with a memory. Ask for a fact and you do not get a guess. You get a receipt.

Elevation, rainfall, how much forest stood here last year, how a coastline has moved: each answer comes back signed with its value, place, and time. Anyone can verify it without trusting us, and any other agent can cite it tomorrow and reproduce it byte-for-byte. The address is the same on every node, so two agents asking about the same ground reach the same memory.

why it holds

Shared, so it compounds. Signed, so it can’t be faked.

Because the memory is shared, agents stop re-deriving the world from scratch and build on each other’s verified work. Because every fact is signed and content-addressed, no one can quietly slip a wrong one in, the way a poisoned note can be planted in an ordinary agent’s private memory (MINJA, NeurIPS 2025). And because four independent foundation models read the same ground, Clay, Prithvi, Tessera, Galileo, their agreement becomes a signal you can act on, while their disagreement is recorded and scored, never averaged away.

what it’s for

What an agent can finally do, responsibly.

Give an agent a memory of Earth it can cite, and the actions it can stand behind change.

  • Prove a shipment’s land was never cleared, the audit the EU now requires under its Deforestation Regulation, in a year the tropics lost a record 6.7 million hectares of primary rainforest (WRI / Global Forest Watch).
  • Raise a flood or wildfire flag a day sooner. A single day of warning can cut disaster damage by up to a third (UN Early Warnings for All).
  • Keep a carbon credit honest with continuous, signed evidence instead of a once-a-year spot check.
  • Remember any place well enough to defend a decision (a price, a claim, a route) with the receipt attached.

where this goes

Where this is going.

emem is built to be a protocol, not a single service. Because every fact is content-addressed and signed, any responder can serve it and any client can verify it offline, without trusting the source. Today that runs as one hosted responder plus self-hosted nodes. The design target is a federation of independent responders that resolve the same content ids byte-for-byte, cross-cite each other’s attestations, and record where they disagree, so the shared memory gets more trustworthy the more agents read and write against it.

None of the multi-host federation routing ships in 0.0.9. What ships today is the substrate that makes it possible: content addressing, signed receipts, typed temporal edges, multi-attester contradiction scoring, and a deterministic refinement loop.
