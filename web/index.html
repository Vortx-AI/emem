Where space meets AI · Verifiable memory

The memory of the physical world. Search it. Every answer is signed.

Ask about any place, field, river, forest or building. emem reads it from orbit and from open sensors, keeps every reading at one address, and signs it, so any AI can read the answer back and check it.

When web search misses, space answers.

Most of the physical world was never written about, and what was written goes out of date. Satellites pass over every place on Earth every few days and measure it the same way each time. emem turns those passes, and the open sensors and models beside them, into a memory an AI can cite.

Nobody wrote about it
emem reads the place itself, from the source.
The page is out of date
emem reads the latest pass, and still holds the earlier ones.
The answer must hold up
emem signs it, and anyone can check it offline.

The memory model

One reading, one address, one name, one signature.

Five lines define every memory emem holds. Here they are, filled in with the reading at the centre of that Punjab field on 17 November 2026.

Encode and decode

Encode where the data is generated. Decode with any AI.

Nothing is copied into a model and nothing is retyped from a screenshot. The record is signed at its source, and every model that reads it reads the same bytes.

Shared, verifiable memory

One memory for every agent, team and vendor.

Same bytes for every reader

A token names one record. Any agent that resolves it gets byte-identical content, so two agents never cite two versions of one fact.

Nothing changes quietly

Every record goes into an append-only log that independent operators co-sign. A fault is corrected in the open, with a signed erratum.

Check it without us

Each answer verifies offline against a published key, or in the browser at /verify.

Gaps are stated

Where nothing qualifies, a signed absence says where emem looked and why, so silence is never taken for an answer.

Build with it

One URL for every agent. No key to read.

claude mcp add --transport http emem https://emem.dev/mcp
curl -s https://emem.dev/v1/ask -H 'content-type: application/json' \
  -d '{"q":"What is the air quality in Delhi right now?"}'
pip install ememdev

from ememdev import Client
with Client() as em:
    cell = em.locate("Mount Fuji")["cell64"]
    facts = em.recall(cell, bands=["copdem30m.elevation_mean"])
    print(facts["facts"][0]["value"])
