Give your AI a memory of the real world it can check.

the underlined verb is live: it opens /verify

AI models forget. When a long session is summarized, or a task hands off to another agent, the facts they checked blur into paraphrases and the numbers quietly drift. emem is a shared memory that fixes that: every fact about a real place becomes one short, signed line an agent can keep. It survives summarization, moves cleanly between agents and sessions, and resolves back to the exact value, which anyone can re-check without trusting the source.

Built for the agents, robots, and world models that need to reason from the same facts, and for the teams behind them. The facts are grounded in open Earth observation, checkable by anyone, with no account needed.

1

It survives compression

The token carries the address of a fact, not the fact. When a model summarizes a long conversation and drops the numbers, the handle stays and re-hydrates the exact signed bytes.

blake3 CID, canonical CBOR. About 50 tokens versus roughly 1,600 for the full signed fact, near 30x less context (measured with tiktoken).
2

It hands off between agents

One agent passes the token to another. No shared database, no re-embedding, no re-describing. Resolve is a read by content hash straight from the store, so the next agent pays no upstream cost.

Materialize once, cite many. About 180 ms cold, 10 ms warm; every receipt reports its own p50 and p99 latency and a was_cached flag.
3

Anyone can check it

The token resolves to an ed25519 receipt. Recompute the hash and the signature offline and the value stands on its own, with the tamper-provenance class attached, no need to trust the server.

ed25519 receipt, offline verify at /verify. Provenance per fact: direct sensor, deterministic index, model output, or human curated.

06 In three dimensions

An area of the memory, in 3-D

Every splat is one cell of signed facts. Its height, tilt, thickness, and colour are each a measurement with its own fact_cid, so nothing is interpolated and nothing is invented. Where the memory has no fact, there is no splat, and any splat re-checks at /verify.

Grand Canyonelevation, each gaussian lying in the terrain's tangent planesigned elevation facts Interlakenelevation, Sentinel-2 NDVI, and JRC water fused per cellsigned facts Cairo & Gizacolour from a 128-D foundation embedding, no land-cover labelssigned facts Rondôniaheight is biomass, thickness its published standard errorsigned facts

The four above are sparse: one splat per signed fact, small enough to move over MCP or REST and rebuild from the repo. emem.dev/splats is the dense counterpart, a photoreal world you navigate where the same signed facts are densified and every splat is tagged measured, interpolated, or synthesized over an ed25519-signed measured trust root. Connect an agent or self-host

Reach it over MCP or REST with the same handlers, discover everything at /openapi.json, and run your own copy with one docker run under Apache-2.0.
