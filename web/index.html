          How it works

          Your tab tokenises this page live, one step at a time.

          1. readthis pagebytes
          2. split…units
          3. hash…blake3 per unit
          4. fold…one root
          5. log…signed head
          6. name…26 chars
          7. check…offline

            Build with it

            claude mcp add --transport http emem https://emem.dev/mcp
            curl -s https://emem.dev/mcp -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"emem_locate","arguments":{"place":"Lusail"}}}'
            pip install ememdev
            from ememdev import Client

with Client() as em:
    cell = em.locate("Mount Fuji")["cell64"]
    facts = em.recall(cell, bands=["copdem30m.elevation_mean"])
    print(facts["facts"][0]["value"])
