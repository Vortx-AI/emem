how each value is made
blake3
BLAKE3-256 of every byte, base32 lowercase, 52 characters
name
its first 16 bytes, 26 characters: the file_cid emem gives these bytes when they are written as a note
root
the root: a pointer.v1 note states over 4 MiB rows at its source: leaf = blake3(u64_be offset ‖ u64_be length ‖ chunk hash), node = blake3(left ‖ right), an odd node promoted
log
sends the 52-character hash, never the file, to /v1/log/inclusion; a hit is checked here against the signed head

publish it as one link

Not because it is cached.
Because the answer has an address.

Two calls, right now, from your browser to production. Watch the line under them: that is the address the answer lives at, and it is the same both times.

Nothing has run yet. Press the button and both calls go out to emem.dev.

Your context ends.
The address does not.

A token is short enough to sit in a sentence and exact enough to name one measurement. Keep it when your context is compacted, hand it to another agent, resolve it a year later: the same signed bytes come back.

This takes a real token from production and turns it back into the fact it names.

You do not have to trust us.
That is the point, and you can test it.

Every answer carries an ed25519 receipt that checks against a published key rather than against our word. Here is the responder auditing its own fact plane, live, and reporting false when it fails.

The same call you could make from your own machine, with nothing of ours in it.

what is checked, and what we do not claim

Two agents, two vendors,
one set of bytes they both read.

Neither has to trust the other, and neither has to trust us. The tree on your left is redrawn from nothing every time you load this page. The network on your right is drawn from mulberry32(20260826) and has not moved since that seed was written down. Press the button and watch which one changes: reloading changes the tree and never the network, and the seed is in this page's source so you can run it yourself.

A model is valuable BECAUSE it can answer something nobody wrote down. A record is valuable because it cannot. You want both, which is why there are two banks.

One thing crosses between them,
and it is the token.

Earth is what fills this memory today, because satellites and sensors already measure it and their output can be recomputed. It is the substrate, not the subject: anything that can prove how it was produced can be written down the same way.
