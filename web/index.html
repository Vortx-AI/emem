The external memory of our physical world.

Shared, verifiable memory for AI agents. Every place has one address, every observation is one signed fact, and any agent can check any answer offline: no key, no account, no trust in us required.

Every agent forgets when its context ends, and no two agents trust each other's memory. Here the fact itself is what you keep, and the machines observing the world, satellites first, write into it as agents themselves.

One token, evolved into nine shapes

The handle above is the original: one signed fact. As emem grew to carry objects, sets, fields over time, and now the machines themselves, the token grew typed variants, one per shape of memory. All of them are short addresses you can hand to another agent, but they are not equally strong, and the difference decides what a citation actually proves. emem:fact: hashes the complete signed body at full width, so it re-hydrates byte-identical for whoever holds it. emem:entity: and emem:bundle: hash an identity anchor and a citation list rather than the record itself, so they converge two agents on the same object or the same set without promising the same bytes underneath. emem:cell: is an address, not a digest: it names a place, and nothing verifies until a fact hangs on it. Each card opens its entry in the reference, which states what that shape binds.

01 The problem

Two agents, one river, two different rivers

Ask two models about the same place and each writes its own description. Both are plausible, neither is wrong in a way you can point at, and they are no longer about the same thing. That is referential drift, and it compounds every time one agent hands another a paraphrase.

Beside this is a recording, not an illustration: one signed NDVI measurement handed along a chain of live models, Gemma to Qwen and back, each asked only to summarise for the next. Watch the precision leave. Then watch the same chain carry the address instead.

The fix is boring on purpose: name the thing once, and let every agent point at the name. A citation resolves to the byte-identical signed body on any conformant responder, so two models grounded on one token reason about one observation instead of two paraphrases of it.

03 The observers

Satellites are agents here

The open archive earns its place by recomputability: anyone can re-fetch the cited source and recompute the value, which makes it the drift anchor everything else is scored against.

Every other machine that watches the world — an operator’s constellation, a robot, a camera, a microscope — is respected as a contributor and never believed on its word alone. Its output is admitted only when the payload digest is bound inside a complete, signed OS execution trace, chained window to window, so a dropped or reordered frame is refused at ingest by name.

A streamed frame becomes a 63-byte emem:trace: token that reconstructs the verified provenance, never the pixels. The admission contracts are public, content-addressed registries.

Open source

Connect an agent or self-host

Install it from the GitHub MCP Registry, or reach it over MCP or REST with the same handlers. Discover everything at /openapi.json, and run your own copy with one docker run under Apache-2.0.

jsonmcp client
{ "mcpServers": { "emem": { "url": "https://emem.dev/mcp" } } }

Or resolve it by name: emem is listed on the GitHub MCP Registry and in the official MCP registry as io.github.Vortx-AI/emem, published under the GitHub organisation that owns the repository. The version marked latest there is the version this responder answers on, and each is one call to check.

bashrest, no key
curl -s -X POST https://emem.dev/v1/recall \
  -H 'content-type: application/json' \
  -d '{"cell":"defi.zb493.xuqA.zcb5f","bands":["weather.temperature_2m"]}' | jq '.facts[0]'
