The memory model

Address it. Name it. Sign it. Cite it.

Every memory emem holds is five lines. Here they are for the October pass at that point on the shore.

address= (cell, band, tslot)(defi.zb565.yOqU.xApA, indices.mndwi, 20748)where, what, when
value= read at the sourceopen water, Sentinel-2 L2A, 22 Oct 2026 05:32Zread from orbit
fact_cid= BLAKE3(canonical CBOR(fact))deqxdntu2clvx2qasongy5bjhvjk7enrdkcyaso65xpg3s2imdzanamed by its bytes
receipt= Ed25519 over (cell, fact_cid)signed with the key in /.well-known/emem.jsoncheckable offline
log= append-only tree, witnessedone of 3.4 million entries, signed headappend, never rewrite

Shared, verifiable memory

Share one memory. Verify every answer.

Read the same bytes

Resolve a token anywhere and get byte-identical content, so two agents never cite two versions of one fact.

Append, never rewrite

Every record joins an append-only log that independent operators co-sign.

Check it offline

Verify any answer against a published key, in code or in the browser at /verify.

Address everything

One address per place, one name per record, one identity per object, for every agent.

Build with it

Build on one URL.

claude mcp add --transport http emem https://emem.dev/mcp
curl -s https://emem.dev/v1/ask -H 'content-type: application/json' \
  -d '{"q":"What is the air quality in Delhi right now?"}'
pip install ememdev

from ememdev import Client
with Client() as em:
    cell = em.locate("Mount Fuji")["cell64"]
    facts = em.recall(cell, bands=["copdem30m.elevation_mean"])
    print(facts["facts"][0]["value"])
