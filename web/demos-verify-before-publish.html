Catch a wrong number before it ships

An agent read a signed reading three turns ago and is about to quote it. This page takes a live reading, writes a sentence with the wrong number next to its citation, and asks emem to grade the sentence.

writes
none; every call is a read
routes
/v1/echo_verify, /v1/guard/verdict
guard
advisory on emem.dev; it blocks nothing

What you will see

  • A number graded against the signed string its token names: a match, a rounding, or a different number.
  • A draft sentence denied with a reason code and the fix to apply, then allowed once the number is right.
  • A sentence that cites the right number for the wrong quantity, and passes.
1token

A reading and the token that names it

Recall returns the latest air temperature at the cell and its emem:fact: token. Resolving the token gives back the exact string that was signed, value_verbatim.


      

    

  


  

    
2echo

    

      
Is my number the signed number?

      
You send the token and the value you are about to say. emem compares it with the signed string and answers matches and drift: rounded when precision was lost, wrong when it is a different number.

      

        
        
      

      

      

    

  


  

    
3guard

    

      
Grade the whole sentence

      
The guard finds every citation in the text, checks each one resolves and verifies, and compares the number written next to it with the signed value. The field is texts, an array.

      

        
      

      

        
        
      

      

      

    

  


  

    
4blind spots

    

      
What the guard does not check

      
It checks the number, not what the sentence says the number is. Both drafts below are run live. The first cites the temperature fact with the right value and calls it rainfall.

      
The second makes a measurable claim with no citation at all, sent with claim_gating: true. Read citations_found and checked: an allow with nothing checked is a verdict over nothing.

      

    

  


  

    
What this does not show

    
    
      
  • That the cited band is the quantity the sentence names. Compare the resolved band with the words yourself; the rainfall draft above shows why.
    • 
      
  • Enforcement. The hosted route answers advisory: true and blocks nothing. To enforce, run your own node: /v1/guard/selfhost gives the procedure.
    • 
      
  • Anything about a citation this responder does not hold. That comes back not_held_here, never a denial; resolve it where it was minted.
