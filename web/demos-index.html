01Walk the protocol

Start here. These show the three claims every other page rests on: an address, a signed fact, and a check you run yourself.

Signed answer in four steps GET /demos/signed-answer

Resolve a place, recall a band, verify the receipt's Ed25519 signature in the browser, then recompute the fact_cid from a second call.

live/v1/locate/v1/recall/v1/verify_receipt
Ask the Earth GET /demos/ask-the-earth

Questions an agent might send, each wired to one endpoint. Run them in order; every answer cites a fact_cid.

live/v1/elevation/v1/air/v1/hunt/v1/state
Memory tokens POST /v1/memory_token · /v1/memory_token/resolve

One string, emem:fact:<cell64>:<fact_cid>, that an agent can paste into chat or long-term memory. Resolving it returns the signed fact body. The link opens the curl recipe; both routes are POST only.

liveemem:fact:
Receipt verifier GET /verify · /verify/<fact_cid>

Paste a fact_cid, a token or a receipt. The page recomputes BLAKE3 over the canonical CBOR and checks the Ed25519 signature against the responder's published key.

liveBLAKE3Ed25519

02Read a place

Four ways to read the stored record for a place: as one vector, as its nearest neighbours, through time, and across an area.

State cube GET /demos/state-cube

view=encoder returns the 128-D Tessera embedding for a cell. view=cube fuses it with sensor and derived bands into one 1792-D vector, with per-band coverage.

live/v1/state/v1/state_multi
Find similar GET /demos/find-similar

Pick a place. emem returns the K nearest cells by cosine similarity over the 128-D Tessera embedding, each with a fact you can recall and verify.

live/v1/find_similar
Trajectory GET /demos/trajectory

One cell, one band, every stored time slot. The page charts the series and lists the fact_cid of each slot, so any single reading can be cited on its own.

live/v1/trajectory
Recall an area GET /demos/recall-polygon

Give a place name and a band. emem reads every cell inside the resolved polygon and returns per-cell facts, an aggregate and a heatmap.

live/v1/recall_polygon

03Scenes and figures

The same signed record, rendered. These pages are heavier and sit off the developer path.

Sparse worlds GET /worlds · /v1/worlds

Four Gaussian-splat scenes: Grand Canyon, Interlaken, Cairo and Giza, and Rondônia. Each splat is one cell of signed facts, 1,024 cells per scene. Click a splat to read and verify its values.

liveone splat = one cell
Dense worlds GET /splats

Navigable splat scenes (Haridwar, Lahaul, London, Srisailam, Tungabhadra and a farm). Every splat is tagged measured, interpolated or synthesized, and the added layers can be switched off. View only.

livemeasured / interpolated / synthesized
Gallery GET /gallery

Pick a place and read eight live values for it: weather, air, vegetation, surface heat, water, forest and elevation. Each value is Ed25519-signed.

live/v1/locate/v1/weather/v1/ndvi

04Machine endpoints

JSON and event streams with no page around them. Open them in a browser or point an agent at them.

Corpus stream GET /v1/stream

Server-sent events. Each tick reports distinct cells, distinct bands, facts scanned and the manifest CIDs, signed with Ed25519.

liveSSE
Agent benchmark GET /v1/benchmark · POST /v1/benchmark/grade

Five items with known answers: two elevation recalls, one NDVI reading at a Lake Erie algal-bloom cell, and two find_similar neighbours. Submit answers and get a score per item.

liverecallfind_similar
Corpus statistics GET /v1/corpus_state_stats

A signed snapshot over a bounded scan of the store: distinct cells, distinct bands, fact counts per band and the manifest CIDs in force.

livesigned

To build your own demo, call any path under /v1/ with fetch or an MCP tool call; see the reference. This page's source is web/demos-index.html.
