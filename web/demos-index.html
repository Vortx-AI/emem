Demos

Each demo calls the live responder at emem.dev from your browser and checks what comes back in the tab: signatures against the published key, hashes against the names they claim. Each one follows a skill from the emem Claude Code plugin.

How to read them

  • A green tick means this page ran the check itself. A dot is a note, not a check.
  • Every check that can pass is followed by a control that breaks the input on purpose, so you can see it fail.
  • Each demo ends with what it does not show.
  1. 1

    A place, a signed number, a receipt

    Type a place. It becomes a cell64 address, then a signed reading with its emem:fact: token. The page checks the receipt's Ed25519 signature and the fact's BLAKE3 content hash, then resolves the token as another agent would.

    skills
    emem-locate-and-recall, emem-verify-receipt
    calls
    /v1/locate, /v1/recall, /v1/facts/<cid>, /v1/memory_token/resolve
    Open
  2. 2

    Catch a wrong number before it ships

    A draft cites a signed fact but carries the wrong value. /v1/echo_verify compares your number with the signed one, and /v1/guard/verdict reads the whole sentence and answers allow or deny with a reason code.

    skills
    emem-verify-before-publish, emem-referential-drift
    calls
    /v1/echo_verify, /v1/guard/verdict
    Open
  3. 3

    Check what another agent handed you

    A fact token and a signed memory note arrive from someone you do not know. The page checks which key wrote the note, over which bytes and at which path, and that the log holds the write.

    skills
    emem-multi-agent-handoff, emem-long-horizon-memory, emem-sign-and-attest (a recorded write)
    calls
    emem_memory_view over /a2a/tasks, /v1/inbox, /v1/log/inclusion
    Open
  4. 4

    Prove the log only grew

    Pin a signed tree head, prove one entry is in it, then fetch a later head and check the consistency proof between the two. Independent witnesses' co-signatures are read and checked the same way.

    skill
    emem-transparency-log
    calls
    /v1/log/sth, /v1/log/inclusion, /v1/log/consistency, /v1/log/witnesses
    Open
  5. 5

    Cite one section of a file

    Cut a document into sections in the tab and fold their hashes into one Merkle root. Change one word and only that section's hash moves. Then prove one unit of a published index against its author's signed root.

    skill
    emem-tokenise-files
    calls
    /v1/tree/path, /v1/tree/<file_cid>
    Open
  6. 6

    From report text to signed fields

    An invented pesticide-residue report is parsed into rows with results in mg/kg and the MRL it prints. The page checks the text hash, the result hash and the signature, and can OCR a picture of the same report first.

    skill
    emem-document-evidence
    calls
    /v1/lab_report_parse, /v1/ocr
    Open
  7. 7

    One farm field: its edges and its pixels

    Field polygons from Fields of The World over a Sentinel-2 picture, then two native 10 m band grids whose bytes the page re-hashes. NDVI is computed from those grids in the tab.

    skills
    emem-field-signals, emem-field-tokens
    calls
    /v1/field_boundaries, /v1/scene.png, /v1/band_raster, /v1/artifacts/<cid>
    Open
  8. 8

    One plot against the EUDR cut-off

    A cocoa plot checked against the 2020 forest baseline and later forest loss, returned as a signed, Annex II shaped statement. The page checks the receipt and the per-cell facts behind the verdict.

    skill
    emem-eudr-due-diligence
    calls
    /v1/eudr_dds, /v1/facts/<cid>
    Open

Skills without a demo page

The plugin has nineteen skills. Thirteen are shown above. These six have no page of their own, because the demos above cover most of their calls or because what they do is a write this site does not make for you.

  • emem-shared-identityResolve a phrasing to an existing emem:entity: identity, or link and mint one. Minting and linking need tier T3.
  • emem-recall-polygonSigned facts at sampled cells inside an area, with per-cell receipts and the sampling it actually did.
  • emem-urbanOverture buildings and roads, WorldPop, NDBI and night lights, with what each number is measured over.
  • emem-research-grade-citationName the estimand a fact leaves implicit and write a methods paragraph with tokens a reviewer can resolve.
  • emem-find-similarNearest neighbours over a stored embedding. The embedding band is retired on emem.dev, so the index is frozen.
  • emem-device-tracesResolve and re-verify a device's signed OS trace. One software-only host is enrolled; no hardware root of trust is admitted yet.

Run the same steps as an agent

The skills ship in the emem plugin for Claude Code, with offline verifiers in plain Python. Each skill is also served as markdown at https://emem.dev/skills/<name>/SKILL.md.

/plugin marketplace add Vortx-AI/emem
/plugin install emem@emem

3D worlds, unfinished

Eight places are rebuilt as Gaussian-splat scenes, each with a ledger of the signed Sentinel-2 facts it stands on.

more

Both viewers load, but most splats are interpolated rather than measured (0.6% measured at Haridwar), and each world's ledger resolves to signed Sentinel-2 facts. The worlds page lists each one, what it is built from and what is missing.
