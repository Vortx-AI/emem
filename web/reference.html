01Tokens

A token is a short address one agent hands another. Resolving it returns the signed bytes it names. The family says what it binds, and the families are not equally strong.

TokenNamesBindsMintResolve
emem:fact:<cell64>:<fact_cid>one signed reading at a placethe whole body, full 32-byte BLAKE3/v1/memory_token/v1/memory_token/resolve
emem:fact:<lat>,<lng>@<date>@<band>:<fact_cid>the same reading, readablethe body; place, band and date checked against it/v1/memory_token with band and observed_on/v1/memory_token/resolve
emem:bundle:<bundle_cid>a set of factswhich facts, 16-byte anchor; each member binds its own body/v1/memory_bundle/v1/memory_bundle/<token>
emem:raster:<aoi_cid>:<band>:<tslot>:<derivation_cid>one field over an area at one timearea, band and time, checked against a signed derivation record/v1/band_raster/v1/raster/resolve
emem:cube:<aoi_cid>:<band>:<lo>..<hi>:<derivation_cid>a field over timea signed manifest over raster slices; membership recomputed on resolve/v1/band_cube/v1/cube/resolve
emem:rasterset:2 to 64 fields as onea signed manifest of member raster tokens/v1/raster_bundle/v1/raster_bundle/resolve

Field tokens

A raster or cube names an array, so its receipt attests a derivation: this responder computed the artifact whose BLAKE3 is artifact_cid, from a pinned scene, over an area (aoi_cid) and a time slot.

Pixels live in an evictable store at GET /v1/artifacts/{cid}. The signed record persists, so an evicted artifact is rebuilt on dereference rather than lost. To verify, resolve the token and re-hash the artifact against artifact_cid.

Descriptor tokens

A cell64 is a string no model saw in training. Coordinates, a date and a band name are, so the descriptor form reads without a lookup. Both forms resolve to the same bytes.

Resolve checks every claim against the signed body first. The coordinates must quantise to the fact's cell, the band must match, and the date must match a source capture time. A mismatch is 409.

Coordinates with fewer than 5 decimals are refused with 400: 4 decimals is about 11 m, which can land on the neighbouring cell.

Provenance and legacy prefixes

Resolving a fact token also returns its provenance class. direct_sensor and deterministic_index facts are recomputable from the cited source. model_output and human_curated facts carry a caution note in the same payload.

deterministic: true (or a provenance list) on POST /v1/recall keeps only the matching classes, and the filter runs before the receipt is signed. The old prefixes memt:, memb: and meme: still resolve.

A signature proves who signed and that the bytes are unchanged. It does not prove the value is correct.

The MCP layer wraps the same handlers as /openapi.json. Start with emem_ask: it resolves the place, recalls the bands and runs the matching algorithm in one call.

/v1/attest accepts facts only from this responder's key, an enrolled device or a key the operator lists; any other signature gets 403. Per-agent notes and derivations are signed with the agent's own key.

When a cell has no value for a band, the answer is a signed absence with a typed reason, citable like any fact.

05Hunter: find events in a region

/v1/hunt takes an event and a region. It samples up to 32 cells, recalls the event's primary band at each, and returns the top 8 with cell64, value, fact_cid and a scene.png URL.

Free-text questions such as “where is deforestation happening in the Amazon” reach the same path through /v1/ask. Ranking uses the primary band only; the full formula is at /v1/algorithms/<key>.

07Transparency log

Every write is appended to a Merkle log. A client that pins a head can later prove the log only grew.

PathWhat it does
GET /v1/log/sthsigned tree head: (tree_size, root); pin it
GET /v1/log/inclusionaudit path from one entry to the head, by leaf index or entry hash
GET /v1/log/consistencyproof that a later tree extends a head you pinned
POST /v1/log/witnesssubmit a co-signature over a head; refused unless the root matches this log's history
GET /v1/log/witnessesco-signatures on record, with the count of independent operators

The tree uses RFC 6962's construction with BLAKE3-256 in place of SHA-256, so Certificate Transparency tooling will not read it.

What it does not prove

  • It does not stop a split view: the head, proofs and witness list all come from the responder being checked, and there is no gossip between clients.
  • There is no witness allowlist. A co-signature proves a key signed a head, not that the key is independent.
  • A receipt does not chain to the log, so you cannot yet prove a fact you hold is in it.

08The machine contract

This page lists the calls agents use most. The complete contract is /openapi.json, with every documented path under /v1/*.

Nine verbs

The read surface implements the algebra in the memory model. Each verb is an existing endpoint.

VerbSurface
ensure(a, B)POST /v1/recall: reuse what exists, fetch what is missing
valid(M, a)POST /v1/temporal_route: per-band validity, cite_now or fetch_for_intent
diffPOST /v1/diff · /v1/state_diff
mergePOST /v1/memory_bundle: one signed envelope, one citable name
verifyPOST /v1/verify_receipt · /verify in the browser · offline from the receipt bytes
tracein the fact body: derivation.fn_key and sources[]; formulas at /v1/algorithms
competingPOST /v1/memory_contradictions: disagreement kept as scored evidence
cite / resolvePOST /v1/memory_token · /v1/memory_token/resolve
evolvePOST /v1/attest · supersedes edges; nothing is erased

Browse the contract in the API reference (ReDoc). Agent discovery starts at /v1/agent_card, /agent.json or /.well-known/mcp.json.
