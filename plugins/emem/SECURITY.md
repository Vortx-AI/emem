# Security

This plugin is part of emem. The security policy, which says what is supported and how to report a vulnerability, is the repository's [SECURITY.md](https://github.com/Vortx-AI/emem/blob/main/SECURITY.md).

The plugin itself holds no key and no secret. Its scripts read the files you pass them, and the only network calls they make are the ones each skill's "Network use" note names.
